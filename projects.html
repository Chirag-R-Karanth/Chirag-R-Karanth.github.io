01Atomic Orbital

A Python investigation into whether atomic orbitals can be visualised and validated from quantum mechanics directly — numerical wavefunctions, plausible shapes, and a daily argument with the mesh resolution.

PythonNumPySciPy

What it is

A computational look at the hydrogen / orbital wavefunctions. It validates shape and energy predictions numerically rather than trusting a textbook figure — and renders them so the result is actually worth looking at.

Why it exists

The course material stopped at the equations. I wanted to see what they looked like, and to know whether I understood them well enough to implement them.

What I built

  • A solver core for the wavefunction components.
  • Validation against known orbital results.
  • Render pipeline that turns the maths into something visual.

Technical decisions & current state

Kept everything to numpy/scipy so the science stays obvious and the dependencies stay light. Still actively probing — readme honesty included.

This started as "can I render the hydrogen wavefunction without completely losing it?" The repository description literally says "to satisfy my ego" and I am not removing that.

Lesson re-learnt: mesh density is a love-hate relationship, and always check your physical units before trusting a pretty picture.

02Number Plate Detection

OpenCV-based detection and OCR for vehicle number plates — the classic CV project, done starting from the documentation instead of a copy-paste tutorial.

PythonOpenCVOCR

What it is

Detects a plate region in a photo, isolates it, and runs OCR to pull the registration number. My first real computer-vision pipeline.

Why it exists

I wanted a project where the input is messy reality (bad angles, glare, Indian plates) rather than clean demo data.

What I built

  • Contour-based plate localisation.
  • Preprocessing chain tuned for variable light and focus.
  • OCR post-processing to clean up misread characters.

Current state

Solid prototype. Works on bright, straight-on shots; still dreams of handling rain. A good exercise in knowing exactly where each stage loses accuracy.

The first plate I ever pointed this at belonged to my own family's car. The results were… humbling. OCR on regional script variants remains a battle.

The best part of this project is that it taught me to debug by inspecting intermediate images instead of hoping.

05Linux Desktop Ricing

My dotfiles and window-manager setup — an ongoing, zero-shot course in how operating systems actually behave, disguised as making a desktop look good.

LinuxShellConfigs

What it is

A living repository of desktop configuration — window manager, status bars, terminal setup, scripts. Every file is a decision I made and documented by writing it.

Why it counts as a project

Ricing is secretly a systems course, just with better visuals: process management, X / Wayland, daemons, autostarts, and the eternal "why does this config not load" loop.

What it teaches

  • Reading documentation and man pages for fun.
  • Debugging configs by careful elimination.
  • Never trusting a setup script you don't understand.

There is a 3 AM window-manager rabbit hole, and I have fallen into it multiple times. Worth noting that the Blacklight side of this site and the ricing sessions share a timezone: after midnight.
